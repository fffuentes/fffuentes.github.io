# Control Tower de Repuestos

Dashboard ejecutivo para monitoreo de rotación y obsolescencia de inventario de repuestos.

## 📖 Documentación

Toda la documentación del proyecto está en la carpeta [`docs/`](docs/):

| Archivo | Contenido |
|---|---|
| [`DEV_NOTES.md`](docs/DEV_NOTES.md) | Contexto general, filosofía, decisiones de diseño |
| [`ARCHITECTURE.md`](docs/ARCHITECTURE.md) | Estructura, dependencias, flujos, diagramas Mermaid |
| [`CHANGELOG.md`](docs/CHANGELOG.md) | Historial de funcionalidades implementadas |
| [`TODO.md`](docs/TODO.md) | Pendientes priorizados (alta/media/baja) |
| [`CONTRIBUTING.md`](docs/CONTRIBUTING.md) | Reglas y convenciones para modificaciones |
